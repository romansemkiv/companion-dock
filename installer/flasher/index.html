Install or update over USB.

This page puts the Companion Dock firmware on a Waveshare ESP32-P4-WIFI6-POE-ETH board. A box that already runs it can be updated here and keeps its settings.

Looking for the latest firmware

Use a firmware file from this computer

Pick a full image, the one whose name ends in -full.bin. An update takes its parts from the same file.

This browser can't talk to the board. Open this page in Chrome or Edge on a computer (Windows, macOS or Linux). Safari, Firefox and phones don't support USB serial devices.

Three steps.

  1. Connect the board

    Plug the board's USB-C port into this computer with a data cable (the USB-A port is for the Stream Decks). Press Connect and pick the board in the list: “USB Single Serial”, “CH343” or “usbmodem”.

  2. Update or start fresh

    Once the board is connected, the page reads what is on it and offers what fits.

    What to install

  3. Write it

    About 3 minutes. Leave the cable in until the page says it's done. What was written is checked against the file.

The box restarts by itself.

After an update

The box starts in about 5 seconds, joins its network and reconnects to Companion. Its Firmware page and the deck's Box screen show the new version.

After a fresh install

The Stream Decks show the setup screen with two QR codes.

  1. Scan the first code with your phone to join the box's hotspot.
  2. Scan the second to open the setup page, then join your network on its Wi-Fi page, or plug in an Ethernet cable.
  3. Add the box in Companion. How to add it covers both modes.

If it doesn't work.

The board isn't in the list

Try another cable (charge-only cables have no data wires) and plug straight into the computer, not through a hub. On Windows, if no COM port appears, install WCH's CH343 driver.

It can't connect

Close anything else that has the port open, such as a serial monitor or the Arduino IDE. Then put the board in download mode by hand: hold BOOT, press and release RESET, release BOOT, and connect again.

It stopped halfway

Nothing is broken, and an update that stopped has not touched the settings. Press RESET on the board, connect and run it again.

Update isn't offered

The page offers an update only on a board that is laid out the way Companion Dock lays it out, so that the settings it keeps are this firmware's. A new board, or one that ran other firmware, gets a fresh install. A box on the network can also be updated from its own web page, on the Firmware page.

Installing an older version

Choose Fresh install and pick the version in the list under it. An update is always the latest version: it keeps the settings, and settings saved by a newer firmware aren't meant for an older one.
