Companion Dock installer

Puts the firmware on a Waveshare ESP32-P4-WIFI6-POE-ETH board, straight from this page.

This browser can't talk to the board. Open this page in Chrome or Edge on a computer (Windows, macOS or Linux). Safari, Firefox and phones don't support USB serial devices.

Install

…Looking for the latest firmware
  1. Connect the board's USB-C port to this computer with a data cable. The USB-A port is for the Stream Decks.
  2. Press Connect and install and pick the board in the list. It usually shows up as "USB Single Serial", "CH343" or "usbmodem".
  3. Wait until it says it's done, about 3 minutes. Leave the cable in meanwhile.
This is a fresh install. It erases the box's settings: Wi-Fi networks, the settings PIN and the Companion address. To update a box that already runs Companion Dock and keep its settings, open the box's web page and upload the new companion-dock-v….bin on its Firmware page instead.

Use a firmware file from this computer

Pick a full image, the one whose name ends in -full.bin. It's written at address 0x0, like the latest one.

After installing

The box restarts and the Stream Decks show the setup screen with two QR codes.

  1. Scan the first code with your phone to join the box's hotspot.
  2. Scan the second to open the setup page, then join your network on its Wi-Fi page, or plug in an Ethernet cable.
  3. Add the box in Companion. How to add it covers both modes.

If it doesn't work

  • The board isn't in the list. Try another cable (charge-only cables have no data wires) and plug straight into the computer, not through a hub. On Windows, if no COM port appears, install WCH's CH343 driver.
  • It can't connect. Close anything else that has the port open, such as a serial monitor or the Arduino IDE. Then put the board in download mode by hand: hold BOOT, press and release RESET, release BOOT, and try again.
  • It stopped halfway. Nothing is broken. Press RESET on the board and install again.
